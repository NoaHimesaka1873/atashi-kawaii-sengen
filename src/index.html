Stuff I build (mostly: Linux where it shouldn't be)

I'm a member of the t2linux project, which exists to make Linux behave on Intel Macs with Apple's T2 chip. If you follow the official Arch instructions, the install command hands you linux-t2, apple-bcm-firmware and t2fanrd — those come out of my repo, off my mirror. Sorry about that.

linux-t2-arch

the kernel itself

The Arch package for a Linux kernel with bleeding-edge T2 Mac support. Its README describes it as “under new management, with 100% more manga and weebness” — the new management is me. It's also the kernel my own MacBook Pro boots.

80 stars

arch-mact2

[arch-mact2]

The pacman repository the t2linux wiki tells every Arch-on-a-Mac user to add to their pacman.conf. I build the packages, sign them and serve them off my own mirror.

pacman repo · on my mirror

t2fand

t2fanrd.service

A small daemon that controls the fans on T2 Macs, with a config file where you pick your own temperatures and a linear, exponential or logarithmic curve. Without it, Linux lets your Mac cook itself quietly.

11 stars

apple-bcm-firmware

Wi-Fi & Bluetooth

Packages the Wi-Fi and Bluetooth firmware out of macOS Big Sur so T2 and M1 Macs can actually talk to a network under Linux. Deeply unglamorous, deeply necessary.

13 stars

t2strap

the easier path

A pacstrap frontend that makes installing Arch on a T2 Mac less of a transcription exercise. For the people who read the wiki's install command and thought “absolutely not”.

Python

linux-xanmod-edge-t2

the spicy kernel

Xanmod, but with the T2 patches, for when one kernel package is not enough kernel packages. (It never is.)

7 stars

Side quests (the tabs I should have closed)

koreader-nightly-vellum

Every day a robot packages the newest KOReader nightly for reMarkable tablets, signs it and puts it on my mirror, so my e-reader can be on the bleeding edge too. It keeps the last ten. I have a Paper Pro to feed.

Vellum repo

dms-plugin-roon

A DankMaterialShell plugin that puts Roon on my desktop: a now-playing pill in the bar, album art in the popout, library search from the launcher. Written purely so I'd stop alt-tabbing.

QML

roon-extension-mpris

Exposes a Roon zone over MPRIS, so the media keys on my keyboard control the expensive box across the room. This is what audiophilia looks like from the software side.

Node.js

mc-matterbridge-forge

A Forge mod that pipes Minecraft chat — joins, deaths, advancements and all — into Matterbridge, so YuruMC and YuruChat can gossip about each other.
