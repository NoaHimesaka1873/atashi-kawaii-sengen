Stuff I build (mostly: Linux where it shouldn't be)

I'm a member of the t2linux project, which exists to make Linux behave on Intel Macs with Apple's T2 chip. If you follow the official Arch instructions, the install command hands you linux-t2, apple-t2-audio-config and t2fanrd. I build all three in my own pacman repo and serve them off my own mirror (though only the kernel is actually my code).

linux-t2-arch

the kernel itself

The Arch package for a Linux kernel with bleeding-edge T2 Mac support. Its README says “under new management, with 100% more manga and weebness”. The new management is me.

tracks mainline, ships weeb

arch-mact2

[arch-mact2]

The pacman repository the t2linux wiki tells every Arch-on-a-Mac user to add to their pacman.conf. I build 36 packages and serve them off my mirror. The database is signed; the packages themselves are on the honour system, which is why the wiki tells you to set SigLevel = Never. I'm one student with one build machine, not the AUR.

pacman repo · on my mirror

t2fand

the original, in Python

My daemon for controlling fans on T2 Macs. Set your temperatures, pick a curve (linear, exponential or logarithmic) and your laptop stops trying to cook itself. Some T2 Macs run their fans on their own; the ones that don't have nothing but this between them and a very expensive griddle. GnomedDev later rewrote it in Rust as t2fanrd, and I now package that for everyone instead.

Python · superseded by t2fanrd

apple-bcm-firmware

Wi-Fi & Bluetooth

Packages the Wi-Fi and Bluetooth firmware out of macOS Big Sur so T2 and M1 Macs have networking under Linux.

Broadcom firmware packaging

t2strap

the easier path

A pacstrap frontend for installing Arch on T2 Macs. Nobody has ever typed that twelve-package pacstrap line by hand, and this exists so nobody ever has to.

Python

linux-xanmod-edge-t2

the spicy kernel

Xanmod with the T2 patches on top.
