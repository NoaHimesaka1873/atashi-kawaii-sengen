Stuff I build (mostly: Linux where it shouldn't be)

I'm a member of the t2linux project, which exists to make Linux behave on Intel Macs with Apple's T2 chip. The official Arch install instructions pull the kernel and a few packages from my repo, off my mirror. The fan daemon among them is GnomedDev's, not mine. I also run the project's Matrix homeserver at chat.t2linux.org.
